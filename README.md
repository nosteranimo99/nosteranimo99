### What I'm building

[Golden Boot Financial](https://www.goldenbootfinancial.com) is a savings benefit
that employers offer their workers. An employee connects their accounts and gets a
plan for each paycheck, with spending, subscriptions, goals and investments tracked
in one place. The employer sees totals only, never an individual.

- In beta since September 2026.
- I built the product myself, working with AI coding tools.
- Python (FastAPI) and Postgres on the back end, Next.js and TypeScript on the
  front end, Plaid for account connections, Clerk for sign-in.
- The code is private because it handles members' financial data. There is a demo
  on the website.
